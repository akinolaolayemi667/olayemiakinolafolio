# Template pack

Copy **this entire folder** to:

```text
documentation/projects/{slug}/
```

Then fill:

| File | Role |
|------|------|
| [PROJECT.md](./PROJECT.md) | Master source of truth |
| [screenshots.md](./screenshots.md) | Gallery / capture plan |
| [seo.md](./seo.md) | Keywords, SEO, OG, schema |
| [repository.md](./repository.md) | Repo visibility & confidentiality |

Replace `{{TITLE}}`, `{{SLUG}}`, `{{ID}}` everywhere.  
Follow [../WORKFLOW.md](../WORKFLOW.md) and [../SCHEMA.md](../SCHEMA.md).
